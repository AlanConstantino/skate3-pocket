# Credits

Skate 3 Pocket is maintained by **Alan Constantino**. Its additions include the Android driver manager, Turnip loader integration, controller input fallback, restart handling, and testing on the Retroid Pocket 6.

This work depends on substantial work by other developers:

- **[Andrew Nakas](https://github.com/andrewnakas/skate3-android)** — the Android application and platform work. Pocket uses the native engine from Andrew's **v0.1.19** Android release unchanged.
- **[Alex McHugh and Skate3Recomp contributors](https://github.com/mchughalex/skate3recomp)** — Skate 3 recompilation, native rendering, and the Skate-specific runtime work. Andrew's public [ReXGlue runtime fork](https://github.com/andrewnakas/rexglue-skate3) derives from [Alex's runtime fork](https://github.com/mchughalex/rexglue-skate3).
- **[ReXGlue](https://github.com/rexglue/rexglue-sdk)** and **[Xenia](https://github.com/xenia-project/xenia)** contributors — the underlying recompilation and Xbox 360 runtime foundations.
- **Sam Lantinga and [SDL](https://github.com/libsdl-org/SDL) contributors** — the Android input and platform layer.
- **[Mesa/Turnip](https://www.mesa3d.org/) contributors** and **[MrPurple](https://github.com/MrPurple666/purple-turnip)** — the optional bundled T30 Vulkan driver and its packaging.
- **Billy Laws and contributors to [libadrenotools](https://github.com/bylaws/libadrenotools) and [liblinkernsbypass](https://github.com/bylaws/liblinkernsbypass)** — custom driver loading on Android.
- **[FFmpeg](https://ffmpeg.org/) contributors** — media codec code present in the upstream native engine.

Skate 3 was created by EA Black Box and published by Electronic Arts. This is an unofficial community project. Credit does not imply endorsement by the original developers, publishers, or upstream projects.
